# VoiceGrep для Android

Приложение-компаньон к [VoiceGrep](https://voicegrep.com) для Mac: встречи, транскрипт, разбор
участников, ассистент и запись встречи в комнате прямо с телефона. Mac остаётся главным — встречи
хранит и обрабатывает он, телефон показывает их и отправляет правки и записи обратно на Mac.

Здесь только релизы (APK). Android 10+.

## Установка

Скачайте `VoiceGrep-Android-<версия>.apk` из [последнего релиза](https://github.com/ilyabazhenov/voicegrep-android/releases/latest)
и откройте его на телефоне (Android попросит разрешить установку из этого источника).

### Автообновления через Obtainium

В [Obtainium](https://github.com/ImranR98/Obtainium) нажмите «Add App» и вставьте адрес:

```
https://github.com/ilyabazhenov/voicegrep-android
```

Obtainium будет сам находить новые версии в релизах этого репозитория.

## Подключение к Mac

1. На Mac: VoiceGrep → «Настройки → Данные → Телефон», включите «Доступ с телефона» (по умолчанию выключено).
2. Нажмите «Подключить телефон…» и отсканируйте QR-код приложением. В первый раз телефон и Mac должны быть в одной сети Wi-Fi.
3. Вне дома телефон подключается через relay: он передаёт только зашифрованные данные. Mac при этом должен быть включён.
